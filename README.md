# 🧮 Cynla Calculator

### Calculadora Vintage desenvolvida com Inteligência Artificial

A **Cynla Calculator** é uma aplicação de calculadora com interface inspirada nos equipamentos eletrônicos dos anos 1970 e 1980, combinando um design vintage com funcionalidades matemáticas essenciais.

O projeto foi idealizado durante um desafio de aprendizagem sobre **Inteligência Artificial aplicada ao desenvolvimento de software**, utilizando o **Google AI Studio** como ferramenta de apoio à criação e compreensão do código.

## 🎯 Objetivo

Explorar como a Inteligência Artificial pode auxiliar na construção de aplicações, desde a elaboração da interface até a implementação da lógica de programação.

O projeto também busca compreender conceitos fundamentais, como variáveis, funções, operadores matemáticos, condições e interação com o usuário.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Operações com números decimais
- 🧹 Limpeza do visor
- ⌫ Exclusão de dígitos
- ⚠️ Tratamento de erros, incluindo divisão por zero
- 🎨 Interface inspirada em calculadoras vintage

## 🎨 Identidade visual

A Cynla Calculator utiliza a estética **Vintage Retro Tech**, com cores suaves, teclas inspiradas em calculadoras físicas e um visor digital com aparência de LCD.

A paleta de cores inclui bege creme, verde oliva, marrom escuro, laranja queimado e verde LCD.

O objetivo é oferecer uma experiência simples, intuitiva e visualmente agradável.

## 🛠️ Tecnologias

- **Python** — linguagem principal da aplicação.
- **Tkinter** — biblioteca gráfica prevista para a interface desktop.
- **Google AI Studio** — ferramenta de Inteligência Artificial utilizada como apoio ao desenvolvimento.
- **GitHub** — plataforma de versionamento e compartilhamento do projeto.

## 🚀 Como executar

Para executar a versão Python no computador:

1. Instale o Python 3.
2. Clone o repositório ou baixe os arquivos do projeto.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python cynla_calculator.py
```

É necessário que o ambiente Python tenha suporte ao Tkinter.

## 🧠 Aprendizado com Inteligência Artificial

A construção da Cynla Calculator faz parte do desafio **"Criando sua primeira aplicação com IA"**.

Durante o desenvolvimento, são exploradas questões como:

- Quais são os principais componentes do código?
- Como a aplicação recebe os números e identifica as operações?
- Como a lógica de programação realiza os cálculos?
- Como os resultados são apresentados ao usuário?

Mais do que criar uma calculadora, o propósito é compreender como a Inteligência Artificial pode contribuir para o aprendizado de programação e a criação de soluções digitais.
